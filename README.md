# ДМБ Таймер (Нативное Android-приложение)

Готовый проект на Kotlin + Jetpack Compose.

## Способ 1: Сборка APK в облаке за 2 минуты (без установки программ на ПК)
1. Создайте бесплатный репозиторий на GitHub и загрузите туда все файлы из этого архива.
2. Перейдите во вкладку **Actions** -> выберите **Build Android APK** -> нажмите **Run workflow**.
3. Через 2 минуты скачайте готовый файл `DmbTimer-APK` (`app-debug.apk`) и установите его на Android-телефон.

## Способ 2: Сборка через Android Studio
1. Откройте папку `DmbTimerAndroid` в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Нажмите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
